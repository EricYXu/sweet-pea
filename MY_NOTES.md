# Earbud Wearable

## Problem Definition

People have tens of hundreds of conversations a day. Conversations allow us to learn new things and gain new information, but a common problem is that we tend to forget what we talk about. This prevents us from truly maximizing our learning gain from our conversations. This app helps by recording conversations for later reflection and learning.


## Goal

The goal of this app is to track a person's conversations as they go about their day. These conversations are first interpreted and then summarized for the user to look back on after the recording has completed. The app should be able to track conversations for long periods of time (~3-6 hours), and should filter out irrelevant conversations.


## Must-Have Key Features

1. Conversation recording: the user should be able to start a recording session (much like someone starts a workout on Strava), which lets the app then track conversations in the user's ambient environment. 

2. Conversation transcription: the app should be able to convert the audio it captures into text.


## App Layout

For now, I want this app to be a minimum viable product, emphasizing key functionality over excessive features.

- Dashboard: set of vertically stacked cards, where each card has a title that summarizes the conversation. Upon clicking the card, the user can see the conversation transcript along with the different speakers. The format of the conversation transcript could resemble that of a play.

- Record button: a button in the center of the bottom navigation bar that they user can click to begin a recording session. The button should change shape or change the look of the app page to signal to the user that the app is now recording.
